# Badge

A short fact that never changes on its own, such as New.

## Rules
- badge-text-only NEVER Put an icon in a Badge, because the label already says it.
  - Wrong: `<Badge><Icon icon={Add} />New</Badge>`
  - Correct: `<Badge>New</Badge>`
